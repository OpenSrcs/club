# Clubrs

Clubrs is a Rust library for interacting with various Club services. It provides a simple and ergonomic API for developers to integrate Club services into their Rust applications and services.

## Features
- Accounts API
- Transactor API
- Clubkvs API

At the moment clubrs is in a very early stage of development and it is not really ready for use ouside of the OpenSrcs project team. It's API coverage is not complete and covers only functionality which is requred by other Rust based club services.

Once it will become more mature, it will be published to crates.io and the documentation with example will be provided.
